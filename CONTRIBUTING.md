# Contributing to Pastry

Thanks for your interest in contributing to Pastry!

## How to contribute

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes.
6. Commit your changes.
7. Push your branch.
8. Open a Pull Request.

## Development guidelines

- Keep changes focused and minimal.
- Don't introduce unnecessary dependencies.
- Maintain macOS 11+ compatibility.
- Test changes before submitting a Pull Request.
- Don't include passwords, API keys, certificates, or other secrets.
- Don't commit build artifacts such as `.app` or `.dmg` files unless specifically required.

## Pull Requests

Please explain:

- What you changed
- Why you changed it
- How you tested it
- Any compatibility considerations
